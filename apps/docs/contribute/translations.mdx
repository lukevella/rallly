Rallly is available in more than 15 languages. Translations are generated with AI, and anyone can correct them by opening a pull request on GitHub.

## How translations work

New or changed English text is translated into every supported language by a workflow, which opens a pull request titled "🌐 Update translations". The workflow runs whenever English text changes on the main branch, so a translation usually appears within a few hours of the English text being merged. Each translation is checked before it is accepted: variables, tags and plural rules must match the English text.

A glossary keeps product terms consistent within each language. It lives in [`i18n/glossary.json`](https://github.com/lukevella/rallly/blob/main/i18n/glossary.json) and lists how terms such as "Space" or "Event Types" are translated, plus names that are never translated, such as "Rallly" and "Pro".

## Correcting a translation

If a translation is wrong or reads awkwardly, edit it directly and open a pull request. Translations live in JSON files, one folder per language:

| Part of Rallly | Files |
| --- | --- |
| The app | [`apps/web/public/locales/<language>/app.json`](https://github.com/lukevella/rallly/tree/main/apps/web/public/locales) |
| The website | [`apps/landing/public/locales/<language>/`](https://github.com/lukevella/rallly/tree/main/apps/landing/public/locales) |
| Emails | [`packages/emails/locales/<language>/emails.json`](https://github.com/lukevella/rallly/tree/main/packages/emails/locales) |
| Blog posts | [`apps/landing/src/posts/<language>/<post>.md`](https://github.com/lukevella/rallly/tree/main/apps/landing/src/posts) |

Each JSON file maps a key to its text. Find the key by searching for the English text in the matching file under `en`, then change the value in your language's file.

A blog post is translated as a whole Markdown file. Edit the text, but keep links, images, code and components such as `<FaqItem>` exactly as they are in the English post, or the check rejects the file.

Your correction is kept. The workflow only translates a string again when its English text changes, and it uses your version as a starting point when it does.

If a term is translated inconsistently across many strings, fix the existing strings and add the term to the glossary in the same pull request. The glossary only guides future translations; it doesn't change strings that are already translated.

## Tips for translators

Here are a few things to keep in mind when editing a translation.

### Punctuation

Pay close attention to how phrases are punctuated.

```
Name:
```

If a sentence ends with a period (.) or a colon (:), include it in your translation.

```
❌ Nombre
✅ Nombre:
```

### Variables

Variables are placeholders for content that can change. They look like this:

```
Hi {name}, welcome back!
```

`{name}` is replaced with the user's name. Leave variables unchanged.

```
❌ Salut {nom}, bienvenue!
✅ Salut {name}, bienvenue!
```

### Tags

Tags create a link or change how some text looks (for example bold or italics). They look like this:

```
Go to <a>page</a>
```

Keep the tags wrapped around the same content and don't translate them. Translate the text between the tags, unless it is a [variable](#variables).

```
❌ Gehen Sie zur Seite
❌ <a>Gehen Sie zur Seite</a>
❌ Gehen Sie zur <a>page</a>
✅ Gehen Sie zur <a>Seite</a>
```

### Plurals

<Note>
  We use [ICU message format](https://unicode-org.github.io/icu/userguide/format_parse/messages/)
  for plurals.
</Note>

Plurals make sure a message reads correctly for different numbers. The following message displays **1 option** if count is `1`, or **2 options** for anything else:

```
{count, plural, one {# option} other {# options}}
```

`#` is a placeholder for the value of `count`.

If your language needs more plural forms, add them. Every plural must keep its `other` case, and any exact number cases such as `=0`.

```
{count, plural, one {# опция} few {# опции} many {# опций} other {# опции}}
```

### Register

For languages with informal and formal registers, use the **informal** register unless your language's existing translations do otherwise. If you're not sure, please [reach out](#contact).
