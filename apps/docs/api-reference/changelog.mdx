<Update label="2026-11-10">
The private API at `https://app.rallly.co/api/private` is removed. Every request to it returns `410 Gone` with the `GONE` error code. `/v1` is unchanged. See [Migrating from the private API](/api-reference/migrating-from-the-private-api).
</Update>

<Update label="2026-09-22">
- `GET /polls/{pollId}/participants/{participantId}` returns one participant. A missing participant on an existing poll is `404` with `PARTICIPANT_NOT_FOUND`.
- Participants now carry `availability`: one `{ start, end, allDay, modifiers }` span per option they can make, in start order, on both the list and the single-participant endpoint. A span matches an option of the poll by its time; `end` is exclusive; `ifNeedBe` is a modifier.
</Update>

<Update label="2026-09-20">
Webhooks, in beta. A space can register up to five HTTPS endpoints and receive signed, retried deliveries for nine poll and participant events. The event list and payloads may still change, and more events will be added. See [Webhooks](/api-reference/webhooks).

The poll and participant resources are unchanged.
</Update>

<Update label="v1">
Initial stable release under `/v1`.

- Create, list, get and delete polls
- Read a poll's results and participants
- Bearer authentication with space API keys
- Per space rate limits with `RateLimit-*` headers

</Update>
