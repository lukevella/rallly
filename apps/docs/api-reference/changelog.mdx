<Update label="2026-09-14">
`GET /polls/:pollId/participants` now returns every participant in one response. The `cursor` and `limit` query parameters are ignored and the response no longer carries `nextCursor`.
</Update>

<Update label="v1">
Initial stable release under `/v1`.

- Create, list, get, update, close and delete polls
- Read a poll's results and participants
- Bearer authentication with space API keys
- Per space rate limits with `RateLimit-*` headers

Webhooks for poll events are planned. There is no date yet.
</Update>
