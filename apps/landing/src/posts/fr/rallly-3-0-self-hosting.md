Rallly 3.0 a été lancé [en juin dernier](/blog/rallly-3-0) et, depuis, il n'était disponible que pour les utilisateurs de la version hébergée dans le cloud sur [rallly.co](/). Aujourd'hui, j'ai le plaisir d'annoncer la sortie officielle de Rallly 3.0 en auto-hébergement, faisant de Rallly la meilleure alternative auto-hébergeable à Doodle.

![Captures d'écran de Rallly](/static/images/splash.png)

## Comment l'utiliser

Pour savoir comment auto-héberger votre propre instance de Rallly, consultez la [documentation sur l'auto-hébergement](https://support.rallly.co/self-hosting), qui contient des instructions détaillées pour installer Rallly sur votre propre serveur.

## Tarifs

Cette mise à jour est [disponible gratuitement](https://support.rallly.co/self-hosting/pricing) et permet aux utilisateurs de profiter de toutes les fonctionnalités disponibles ici sur leur propre instance auto-hébergée. Si vous le souhaitez et que vous en avez les moyens, vous pouvez verser une contribution unique pour soutenir la poursuite du développement de ce projet.

## Mise à niveau depuis la version 2.x

Si vous auto-hébergez déjà Rallly, consultez les [notes de version](https://github.com/lukevella/rallly/releases/tag/v3.0.0) pour obtenir des instructions et des informations sur les changements incompatibles.

J'espère que cette mise à jour vous plaira et, comme toujours, n'hésitez pas à me faire part de vos [commentaires](mailto:feedback@rallly.co).

À bientôt !
