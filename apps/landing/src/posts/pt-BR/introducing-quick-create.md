Uma das coisas que diferenciam o Rallly de outras ferramentas de agendamento é a possibilidade de criar enquetes de reunião sem precisar criar uma conta. À medida que o Rallly cresceu e ganhou recursos mais avançados, eu quis garantir que novos usuários ainda pudessem começar rapidamente, tendo também um caminho claro para descobrir tudo o que o Rallly oferece.

A abordagem anterior, que dava acesso completo à plataforma para usuários que não tinham feito login, tinha algumas limitações:

- Os usuários podem não perceber que estão usando a plataforma sem uma conta
- Sem criar uma conta, os usuários correm o risco de perder o acesso às enquetes que criaram
- Os recursos avançados continuam desconhecidos para os convidados
- Oferecer acesso de convidado em todas as páginas cria uma complexidade técnica

Para criar uma experiência melhor para todos, introduzi o **Crie rápido**. Você encontra esse recurso diretamente na [página de login](https://app.rallly.co/login), onde pode criar e gerenciar instantaneamente enquetes de grupo sem precisar criar uma conta. Quando quiser fazer mais, como acessar recursos avançados ou garantir acesso de longo prazo às suas enquetes, você poderá criar uma conta facilmente, e todas as suas enquetes existentes serão adicionadas automaticamente à sua conta.

![Crie rápido](https://rallly-public.s3.us-east-1.amazonaws.com/images/quick-create.png)

Essa mudança me permite focar no desenvolvimento de novos recursos avançados, mantendo a experiência inicial simples e acessível para novos usuários. Esse é o primeiro passo de uma série de melhorias para tornar o Rallly ainda mais fácil de usar e poderoso. Fique de olho nas próximas novidades!
