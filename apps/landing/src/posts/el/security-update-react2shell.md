**Αυτή η ανακοίνωση αφορά μόνο αυτοφιλοξενούμενες εγκαταστάσεις του Rallly.** Αν χρησιμοποιείτε την υπηρεσία φιλοξενίας του Rallly στη διεύθυνση [rallly.co](https://rallly.co), δεν χρειάζεται να κάνετε κάποια ενέργεια. Οι διακομιστές διορθώθηκαν μέσα σε λίγες ώρες από την ανακοίνωση των CVE και δεν υπήρξε παραβίαση κατά το διάστημα αυτό.

---

Εντοπίστηκε μια κρίσιμη ευπάθεια ασφαλείας στα React Server Components, η οποία επηρεάζει το Rallly. Σε εγκαταστάσεις που δεν έχουν ενημερωθεί, η ευπάθεια θα μπορούσε να επιτρέψει σε έναν εισβολέα να εκτελέσει κώδικα εξ αποστάσεως στον διακομιστή σας. Αν η εγκατάστασή σας είναι προσβάσιμη από το διαδίκτυο και δεν χρησιμοποιείτε την πιο πρόσφατη έκδοση, **ο διακομιστής σας διατρέχει σημαντικό κίνδυνο**.

Η ευπάθεια [CVE-2025-55182](https://www.cve.org/CVERecord?id=CVE-2025-55182), γνωστή και ως [React2Shell](https://react2shell.com/), επηρεάζει πολλές εφαρμογές που έχουν δημιουργηθεί με το React 19. Έχουν ήδη αναφερθεί πραγματικές παραβιάσεις, κατά τις οποίες εισβολείς εγκατέστησαν κακόβουλο λογισμικό σε παραβιασμένους διακομιστές.

Επιπλέον, εντοπίστηκαν δύο ακόμη ευπάθειες ([CVE-2025-55183](https://www.cve.org/CVERecord?id=CVE-2025-55183), [CVE-2025-55184](https://www.cve.org/CVERecord?id=CVE-2025-55184)) στο πρωτόκολλο React Server Components (RSC). Παρότι δεν επιτρέπουν την απομακρυσμένη εκτέλεση κώδικα, απαιτούν και αυτές την εγκατάσταση διορθώσεων.

Η ομάδα του React ανακάλυψε αργότερα ότι η διόρθωση για την CVE-2025-55184 δεν ήταν πλήρης, με αποτέλεσμα να απαιτείται μια επιπλέον διόρθωση. Αυτό δημοσιοποιήθηκε ως [CVE-2025-67779](https://www.cve.org/CVERecord?id=CVE-2025-67779).

## Χρονολόγιο

- **3 Δεκεμβρίου 2025**: Η React2Shell ([CVE-2025-55182](https://www.cve.org/CVERecord?id=CVE-2025-55182)) ανακοινώθηκε από την ομάδα του React
- **4 Δεκεμβρίου 2025**: Δημοσίευσα την έκδοση v4.5.7 (ενημερωμένο πακέτο Next.js)
- **8 Δεκεμβρίου 2025**: Δημοσίευσα την έκδοση v4.5.8 (ενημερωμένο πακέτο React, πλήρης προστασία από τη React2Shell)
- **11 Δεκεμβρίου 2025**: Η ομάδα του React ανακοίνωσε δύο επιπλέον CVE ([CVE-2025-55183](https://www.cve.org/CVERecord?id=CVE-2025-55183), [CVE-2025-55184](https://www.cve.org/CVERecord?id=CVE-2025-55184)). Σε απάντηση, δημοσίευσα την έκδοση v4.5.10
- **12 Δεκεμβρίου 2025**: Η ομάδα του React ανακοίνωσε ότι η διόρθωση για την CVE-2025-55184 δεν ήταν πλήρης. Η επιπλέον διόρθωση δημοσιοποιήθηκε ως [CVE-2025-67779](https://www.cve.org/CVERecord?id=CVE-2025-67779). Σε απάντηση, δημοσίευσα την έκδοση v4.5.11

## Απαιτούμενες ενέργειες

Αν φιλοξενείτε μόνοι σας το Rallly, κάντε αμέσως τα εξής:

- **Ενημερώστε** το Rallly στην πιο πρόσφατη έκδοση (v4.5.11 ή νεότερη), ώστε να προστατεύεστε από και τις τέσσερις ευπάθειες CVE. Για λεπτομέρειες, δείτε τις [σημειώσεις έκδοσης](https://github.com/lukevella/rallly/releases/tag/v4.5.11).
- Αν χρησιμοποιείτε την έκδοση v4.5.10, πρέπει να ενημερώσετε στην v4.5.11, καθώς η προηγούμενη διόρθωση δεν ήταν πλήρης.
- Αν χρησιμοποιείτε την έκδοση v4.5.8, η οποία παρείχε πλήρη προστασία από τη React2Shell, πρέπει να ενημερώσετε στην v4.5.11, ώστε να προστατεύεστε από όλες τις ευπάθειες.
- Αν χρησιμοποιείτε την έκδοση v4.5.7, θα πρέπει να ενημερώσετε στην v4.5.11, καθώς η v4.5.7 ενδέχεται να μην παρείχε πλήρη προστασία από τη React2Shell.
- Αν χρησιμοποιείτε έκδοση παλαιότερη από την v4.5.7, είστε ευάλωτοι στη React2Shell και θα πρέπει να ενημερώσετε την εγκατάστασή σας άμεσα.
- **Επανεκκινήστε** όλες τις υπηρεσίες και, αν χρησιμοποιείτε Docker, δημιουργήστε ξανά ή κατεβάστε την πιο πρόσφατη εικόνα.
- **Αν δεν μπορείτε να ενημερώσετε αμέσως**, περιορίστε προσωρινά την πρόσβαση (VPN ή διακομιστής μεσολάβησης ελέγχου ταυτότητας) μέχρι να εγκαταστήσετε τις διορθώσεις.

Μετά την ενημέρωση, επιβεβαιώστε ότι η εγκατάστασή σας αναφέρει την πιο πρόσφατη έκδοση του Rallly και ελέγξτε τα αρχεία καταγραφής για τυχόν προειδοποιήσεις. Για να ελέγξετε την έκδοση, επισκεφτείτε τη διεύθυνση: `<your‑rallly‑instance>/api/status`.
