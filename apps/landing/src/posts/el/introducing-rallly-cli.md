Η αυτοφιλοξενία του Rallly απαιτούσε παλιότερα να αντιγράψετε ένα παράδειγμα `docker-compose.yml`, να το επεξεργαστείτε χειροκίνητα, να επιλέξετε τον δικό σας αντίστροφο διακομιστή μεσολάβησης και να συνδέσετε έναν κάδο S3, αν θέλατε να λειτουργούν οι μεταφορτώσεις εικόνων. Ήταν εφικτό, αλλά κάθε εγκατάσταση ήταν λίγο διαφορετική και η ερώτηση «ρύθμισα σωστά αυτό το σημείο;» επανερχόταν συχνά στα email προς την υποστήριξη.

Έτσι δημιουργήσαμε ένα πλήρες CLI που αναλαμβάνει για εσάς την εγκατάσταση, τη διαμόρφωση και τις καθημερινές λειτουργίες.

## Εγκατάσταση με μία εντολή

```sh
curl -fsSL https://get.rallly.co | bash
```

Το πρόγραμμα εγκατάστασης ελέγχει το περιβάλλον σας, σας καθοδηγεί στη διαμόρφωση (τομέας, email υποστήριξης, SMTP), δημιουργεί τα απαραίτητα μυστικά για εσάς και θέτει τα πάντα σε λειτουργία. Δεν χρειάζεται να επεξεργαστείτε τίποτα χειροκίνητα.

Μια λειτουργική εγκατάσταση περιλαμβάνει πλέον:

- το ίδιο το **Rallly**
- το **PostgreSQL** για τη βάση δεδομένων
- το **Traefik** ως αντίστροφο διακομιστή μεσολάβησης, με αυτόματα πιστοποιητικά Let's Encrypt
- το **Garage** για αποθήκευση αντικειμένων συμβατή με S3, ώστε οι μεταφορτώσεις avatar και εικόνων να λειτουργούν αμέσως

Δεν χρειάζεται πλέον να φέρετε τον δικό σας διακομιστή μεσολάβησης ή χώρο αποθήκευσης αντικειμένων για να αποκτήσετε μια πλήρη εγκατάσταση. Αν προτιμάτε να χρησιμοποιήσετε εξωτερικές υπηρεσίες (διαχειριζόμενο Postgres, AWS S3, το δικό σας Nginx ή Caddy), μπορείτε: ορίστε τις σχετικές μεταβλητές στο `.env` και τα ενσωματωμένα κοντέινερ για αυτές τις υπηρεσίες απλώς δεν θα εκκινούν.

## Διαχείριση με το CLI

Μετά την εγκατάσταση, όλα γίνονται μέσω του CLI `rallly.sh`:

```sh
./rallly.sh start          # Start all services
./rallly.sh stop           # Stop all services
./rallly.sh restart        # Apply .env changes
./rallly.sh status         # Show service status
./rallly.sh logs           # Stream logs
./rallly.sh update         # Pull latest images and recreate containers
./rallly.sh backup         # Back up the database to ./backups/
```

Ιδιαίτερα οι ενημερώσεις γίνονται πλέον με μία μόνο εντολή. Η `./rallly.sh update` λαμβάνει τις πιο πρόσφατες εικόνες, αναδημιουργεί τα κοντέινερ και διατηρεί τα δεδομένα και τη διαμόρφωσή σας. Από προεπιλογή, το CLI χρησιμοποιεί την ετικέτα `lukevella/rallly:4`, επομένως θα λαμβάνετε αυτόματα συμβατές εκδόσεις 4.x.

Επιπλέον, έχοντας περισσότερο έλεγχο πάνω στη στοίβα, θα μπορούμε στο μέλλον να προσθέτουμε υπηρεσίες χωρίς να περιπλέκουμε τη διαδικασία εγκατάστασης ή να απαιτούμε από τους χρήστες να επεξεργάζονται τα αρχεία σύνθεσης.

## Χρησιμοποιείτε ήδη αυτοφιλοξενία;

Αν εκτελείτε ήδη το Rallly από ένα χειροκίνητα επεξεργασμένο `docker-compose.yml` ή `config.env`, υπάρχει ένας αναλυτικός [οδηγός μετεγκατάστασης](https://support.rallly.co/self-hosting/migration) που σας καθοδηγεί στην αναβάθμιση στην έκδοση 4.10 και στη μετάβαση στο CLI χωρίς απώλεια δεδομένων. Το σημαντικότερο στοιχείο που πρέπει να μεταφέρετε είναι το `SECRET_PASSWORD`, το οποίο κρυπτογραφεί τις συνεδρίες.

## Από πού να ξεκινήσετε

Στόχος αυτής της έκδοσης ήταν η αυτοφιλοξενία να μοιάζει περισσότερο με ολοκληρωμένο προϊόν παρά με μια απλή συνταγή. Αν αντιμετωπίσετε οποιοδήποτε πρόβλημα στην πορεία ή έχετε ιδέες για το τι θα πρέπει να ακολουθήσει, θα χαρώ να σας ακούσω στη διεύθυνση [feedback@rallly.co](mailto:feedback@rallly.co).
