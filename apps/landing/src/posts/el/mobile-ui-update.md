Γνωρίζατε ότι πάνω από τους μισούς χρήστες του Rallly χρησιμοποιούν κινητές συσκευές;

![Device data](/static/images/device-data.png)

Η [πρώτη μεγάλη ενημέρωση](/blog/new-version-announcment), που κυκλοφόρησε μόλις πριν από δύο εβδομάδες, αντιμετώπισε ήδη αρκετά προβλήματα ευχρηστίας, προσθέτοντας ειδικά στοιχεία περιβάλλοντος χρήστη για κινητές συσκευές. Σήμερα συνεχίζω πάνω σε αυτή τη βάση για να προσφέρω μια ακόμη καλύτερη εμπειρία χρήσης. Τι νέο υπάρχει;

## Ομαδοποιημένες ώρες

Οι ώρες ομαδοποιούνται πλέον ανά ημέρα.
Αυτό απομακρύνει αρκετή ακαταστασία από το περιβάλλον χρήστη και θα πρέπει να βοηθήσει συνολικά στην αναγνωσιμότητα της σελίδας.

![Grouped times - Before and After](/static/images/grouped-times.png)

## Κινούμενα στοιχεία

Η ενημέρωση περιλαμβάνει μερικά όμορφα κινούμενα στοιχεία που δεν είναι μόνο ευχάριστα, αλλά βοηθούν επίσης να καθοδηγούν τους χρήστες προς τη σωστή κατεύθυνση.
Το πεδίο ονόματος και το κουμπί αποθήκευσης συχνά περνούσαν απαρατήρητα, οπότε τα κινούμενα στοιχεία θα βοηθήσουν να τραβήξουν την προσοχή σε αυτά.

![Device data](/static/images/animations.gif)

## Μεγαλύτερη επιφάνεια αφής

![Device data](/static/images/touchable-area.png)

Προηγουμένως, έπρεπε να αγγίξετε το μικροσκοπικό πλαίσιο επιλογής στα δεξιά για να αλλάξετε μια ψήφο. Αρκετά ενοχλητικό αν χρησιμοποιείτε μια μικρή οθόνη. Αυτό όμως δεν ισχύει πλέον. Ολόκληρη η γραμμή μπορεί τώρα να δεχτεί άγγιγμα, επομένως δεν χρειάζεται να έχετε την ακρίβεια σκοπευτή για να επιλέξετε τις σωστές επιλογές.
