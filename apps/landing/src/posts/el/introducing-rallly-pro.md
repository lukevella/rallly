Με ενθουσιασμό ανακοινώνω μια σημαντική ενημέρωση που θα είναι σύντομα διαθέσιμη - το Rallly Pro. Πρόκειται για ένα νέο επί πληρωμή πρόγραμμα που θα προσφέρει νέες δυνατότητες στους συνδρομητές και θα βοηθήσει στη χρηματοδότηση ενός νέου κύκλου ανάπτυξης λειτουργιών, που είμαι σίγουρος ότι θα σας αρέσουν πολύ.

Για αρχή, οι χρήστες του Rallly Pro θα απολαμβάνουν τα εξής οφέλη:

## 1. Οριστικοποίηση ψηφοφοριών και αποστολή προσκλήσεων ημερολογίου

![Οριστικοποίηση μιας ψηφοφορίας](/static/images/introducing-rallly-pro/finalize-poll-demo.gif)

Οι χρήστες του Pro θα μπορούν να επιλέγουν μια τελική ημερομηνία για την ψηφοφορία και να στέλνουν προσκλήσεις ημερολογίου σε όλους τους συμμετέχοντες. Πρόκειται για μια δυνατότητα που ζητήθηκε από πολλούς και την οποία σκοπεύω να συνεχίσω να βελτιώνω και να προσαρμόζω στις ανάγκες των χρηστών του Pro.

## 2. Υποστήριξη κατά προτεραιότητα

Ως χρήστης του Rallly Pro, θα λαμβάνετε υποστήριξη κατά προτεραιότητα και αποκλειστική πρόσβαση σε ζωντανή συνομιλία μέσα στον ιστότοπο.

## 3. Ψηφοφορία για την ανάπτυξη λειτουργιών

Θα ξεκινήσω να πραγματοποιώ έρευνες μεταξύ των χρηστών του Rallly Pro, για να δω ποιες λειτουργίες θα θέλατε να προστεθούν, και οι ψήφοι σας θα επηρεάζουν άμεσα το τι θα υλοποιείται πρώτο.

## 4. Παρατεταμένη διάρκεια ψηφοφοριών

Οι χρήστες του Rallly Pro μπορούν να διατηρούν τις ψηφοφορίες τους επ' αόριστον και δεν θα χρειάζεται να ανησυχούν μήπως χάσουν τα δεδομένα τους.

## 5. Επερχόμενες λειτουργίες

Μπορείτε να περιμένετε να προστεθούν σύντομα περισσότερες λειτουργίες, όπως:

- Ορισμός προθεσμίας
- Αποστολή αυτόματων υπενθυμίσεων
- Απόκρυψη των ονομάτων των συμμετεχόντων

Έχω επίσης δημοσιεύσει μια ανάρτηση που παρουσιάζει [το μέλλον του Rallly](/blog/the-future-of-rallly), το οποίο περιλαμβάνει την προσθήκη περισσότερων λύσεων πάνω από τη δημοφιλή λειτουργία ψηφοφοριών. Με τη βοήθειά σας μπορούμε να κάνουμε αυτό το όραμα πραγματικότητα.
