Το Rallly είχε εδώ και καιρό ένα μικρό API πίσω από μια σημαία λειτουργίας. Μερικοί άνθρωποι το χρησιμοποιούσαν για να δημιουργούν ψηφοφορίες από τα δικά τους συστήματα και τα σχόλιά τους διαμόρφωσαν αυτό που κυκλοφορεί σήμερα. Πλέον είναι διαθέσιμο σε κάθε Χώρο Pro στο Rallly Cloud.

![Ένας επεξεργαστής κώδικα που εμφανίζει ένα αίτημα fetch για τη δημιουργία μιας ψηφοφορίας ημερομηνιών με τρεις επιλογές μέσω του API του Rallly](/static/images/rallly-api/create-poll-editor.svg)

## Τι κάνει

Το API καλύπτει ολόκληρο τον κύκλο ζωής μιας ψηφοφορίας:

- **Δημιουργία ψηφοφορίας** είτε με ολόκληρες ημέρες είτε με χρονικά διαστήματα. Τα χρονικά διαστήματα μπορούν να καταχωριστούν ένα-ένα ή να δημιουργηθούν από ένα πρόγραμμα, για παράδειγμα κάθε 30 λεπτά από τις 9 έως τις 5 τις καθημερινές, για τις επόμενες δύο εβδομάδες.
- **Καταχώριση και ανάγνωση ψηφοφοριών**, με φιλτράρισμα κατά κατάσταση, με τις ίδιες επιλογές και ρυθμίσεις που βλέπετε στην εφαρμογή.
- **Ανάγνωση αποτελεσμάτων**: τον αριθμό ψήφων ανά επιλογή και ποιες επιλογές προηγούνται.
- **Ανάγνωση συμμετεχόντων** και του τρόπου με τον οποίο ψήφισε ο καθένας.
- **Κλείσιμο ή διαγραφή** μιας ψηφοφορίας όταν έχει ληφθεί απόφαση.

Κάθε αίτημα αφορά έναν συγκεκριμένο Χώρο. Το κλειδί API προσδιορίζει τον Χώρο, επομένως ό,τι δημιουργείτε ή διαβάζετε ανήκει σε αυτόν.

## Ξεκινώντας

Ο κάτοχος του Χώρου δημιουργεί ένα κλειδί από τις **Ρυθμίσεις → Κλειδιά API**. Τα αιτήματα το μεταφέρουν ως bearer token:

```sh
curl https://api.rallly.co/v1/polls \
  -H "Authorization: Bearer $RALLLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Team offsite",
    "kind": "date",
    "options": [
      { "date": "2026-10-05" },
      { "date": "2026-10-06" },
      { "date": "2026-10-07" }
    ]
  }'
```

Η απάντηση περιλαμβάνει ένα `inviteUrl` για κοινοποίηση στους συμμετέχοντες και ένα `adminUrl` για τον διοργανωτή. Κάθε Χώρος μπορεί να κάνει 60 αιτήματα το λεπτό.

Η [αναφορά API](https://support.rallly.co/api-reference/introduction) περιλαμβάνει κάθε endpoint, μαζί με παραδείγματα αιτημάτων και απαντήσεων, ενώ είναι διαθέσιμο και το έγγραφο OpenAPI, αν προτιμάτε να δημιουργήσετε έναν client.

## Τι ακολουθεί

Η αναζήτηση αποτελεσμάτων σε τακτά διαστήματα λειτουργεί, αλλά δεν είναι ο τρόπος με τον οποίο θέλουν να λειτουργούν οι περισσότερες ενσωματώσεις. Σχεδιάζουμε webhooks για συμβάντα ψηφοφοριών, ώστε το σύστημά σας να ενημερώνεται τη στιγμή που υποβάλλεται μια νέα απάντηση ή κλείνει μια ψηφοφορία. Δεν υπάρχει ακόμη ημερομηνία για αυτό. Αν δημιουργήσετε κάτι με το API, θα ήθελα να μάθω τι φτιάχνετε και τι σας δυσκολεύει, στη διεύθυνση [feedback@rallly.co](mailto:feedback@rallly.co).
