你知道嗎？超過一半的 Rallly 使用者都在行動裝置上使用 Rallly。

![裝置資料](/static/images/device-data.png)

[兩週前發布的首次重大更新](/blog/new-version-announcment) 已經透過為行動裝置加入專用的 UI 元件，解決了不少使用上的問題，而今天我會在此基礎上繼續改進，帶來更好的使用體驗。那麼這次有哪些新功能呢？

## 按天分組的時間

現在會依日期將時間分組。
這能減少 UI 中大量雜亂的內容，應該也能讓頁面整體更容易閱讀。

![按天分組的時間－更新前與更新後](/static/images/grouped-times.png)

## 動畫

這次更新加入了一些精心設計的動畫，不僅賞心悅目，也能引導使用者採取正確的操作。
名稱欄位和儲存按鈕常常會被忽略，因此這些動畫應該能幫助使用者注意到它們。

![裝置資料](/static/images/animations.gif)

## 增加觸控範圍

![裝置資料](/static/images/touchable-area.png)

之前，你必須點選右側小小的核取方塊，才能切換投票結果。如果你使用的是小螢幕，這實在相當惱人。不過現在已經不一樣了。整列都可以點選，因此你不需要像神槍手一樣精準，也能選取正確的選項。

## 總結

希望你會喜歡這次更新，也覺得它實用。
我會根據收到的回饋來決定接下來要做什麼，所以不妨在 Twitter 發文給 [@ralllyco](https://twitter.com/ralllyco) 或 [@imlukevella](https://twitter.com/imlukevella)，告訴我你喜歡這次更新的哪些地方，以及接下來想看到什麼功能？
