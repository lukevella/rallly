В Rallly уже некоторое время работает небольшое API, доступное по флагу. Несколько человек использовали его, чтобы создавать опросы из собственных систем, а их отзывы помогли сформировать текущую версию. Теперь API открыто для всех пространств Pro в Rallly Cloud.

![Редактор кода с запросом fetch, который создаёт опрос по датам с тремя вариантами через API Rallly](/static/images/rallly-api/create-poll-editor.svg)

## Что умеет API

API охватывает весь жизненный цикл опроса:

- **Создавать опросы** как на целые дни, так и на временные интервалы. Временные интервалы можно указать по отдельности или сгенерировать по расписанию — например, каждые 30 минут с 9:00 до 17:00 по будням в течение следующих двух недель.
- **Получать список опросов и просматривать их**, фильтруя по статусу, с теми же вариантами и настройками, что доступны в приложении.
- **Просматривать результаты**: количество голосов за каждый вариант и варианты-лидеры.
- **Просматривать участников** и то, как проголосовал каждый из них.
- **Закрывать или удалять** опрос после принятия решения.

Каждый запрос относится к одному пространству. Ключ API определяет пространство, поэтому всё созданное или прочитанное вами относится к нему.

## Как начать

Владелец пространства создаёт ключ в разделе **Настройки → Ключи API**. Запросы передают его как токен носителя:

```sh
curl https://api.rallly.co/v1/polls \
  -H "Authorization: Bearer $RALLLY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Team offsite",
    "kind": "date",
    "options": [
      { "date": "2026-10-05" },
      { "date": "2026-10-06" },
      { "date": "2026-10-07" }
    ]
  }'
```

В ответе будут `inviteUrl`, которым можно поделиться с участниками, и `adminUrl` для организатора. Каждое пространство может отправлять 60 запросов в минуту.

В [справочнике API](https://support.rallly.co/api-reference/introduction) описаны все конечные точки и приведены примеры запросов и ответов. Также доступен документ OpenAPI, если вы предпочитаете сгенерировать клиент.

## Что дальше

Получать результаты с помощью периодических запросов можно, но большинство интеграций работает не так. Вебхуки для событий опросов уже запланированы: благодаря им ваша система сможет сразу узнавать о новом ответе или закрытом опросе. Сроков пока нет. Если вы создадите что-то с помощью API, расскажите, что именно вы делаете и что вам мешает, написав на [feedback@rallly.co](mailto:feedback@rallly.co).
